2. Compilation Command
   
The following GCC command is used to compile a C program with warnings enabled:

gcc -Wall -Wextra -std=c11 main.c -o main

To execute the program:

./main
On Windows, run the compiled program using:

main.exe
3. Steps to Execute Each Program

Open the assignment folder in a terminal.

Save the C source code for each task in a .c file.

Compile the program using GCC with -Wall -Wextra -std=c11.

If compilation succeeds, execute the generated program.

Enter the required input values.

Check the output against the expected result.

Correct any compiler errors or warnings and run the program again.
